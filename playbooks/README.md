# Field Playbooks

Playbooks are short operating procedures for moments where judgment and consistency matter. Tailor them to the customer's environment and name an owner.

| Playbook | Use it when |
|---|---|
| [Discovery sprint](./discovery-sprint.md) | The request is ambiguous or solution-led |
| [Evaluation release gate](./evaluation-release-gate.md) | A prompt, model, retrieval, tool, or workflow changes |
| [Production go-live](./production-go-live.md) | Moving from test/pilot to real users or side effects |
| [AI incident response](./ai-incident-response.md) | Quality, safety, cost, privacy, or availability degrades |
| [Customer handoff](./customer-handoff.md) | Ownership moves from builder to operating team |

Copy the relevant checklist into the project issue. Add a link to the evidence beside each checked item. A check without evidence is only a claim.
