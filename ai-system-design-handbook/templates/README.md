# Copyable working templates

Copy a template into your own project and replace its prompts with specific answers. Keeping an unanswered field visible is better than inventing a fact to make the document look complete.

| Template | Use |
|---|---|
| [Problem brief](problem-brief.md) | Agree on a small useful outcome |
| [Architecture decision record](architecture-decision-record.md) | Explain a choice and its alternatives |
| [Evaluation plan](evaluation-plan.md) | Define quality before comparing candidates |
| [Incident runbook](incident-runbook.md) | Prepare recovery and ownership |
| [ROI worksheet](roi-worksheet.md) | Separate assumed value from measured results |
| [n8n workflow design](n8n-workflow-design.md) | Define nodes, state, review, and replay |
| [Study tracker](study-tracker.md) | Record recall and build evidence |
| [Release manifest](release-manifest.md) | Reproduce a deployed configuration |
