# Same-task review worksheet

Use this original synthetic task to study a product you can access. This repository does not contain completed runs or product rankings.

## Shared input

```text
Project: Example export-help pilot
Confirmed facts:
- The support lead wants a draft triage brief, not automatic customer replies.
- The supplied north-tenant export has 10 rows and 8 unique ticket IDs.
- Latest ticket categories: export 5, access 2, billing 1.
- Root causes and task-handling time have not been measured.
Unavailable evidence:
- No customer-call notes, production logs, or current permission policy.
Deliverable:
- One-page brief with confirmed facts, unknowns, a bounded pilot, and tests.
Boundary:
- Use only this supplied material. Prepare a draft in this conversation.
- Do not contact people, change accounts, create a schedule, or invent sources.
```

Paste the same input and deliverable into each available product. Do not give one product private connected evidence while the others receive only this text. If you later test connected-source research, define that as a separate experiment with its own source inventory.

## Review questions

Did the result preserve **five export tickets out of eight unique tickets**, rather than treating rows as unique work? Did it avoid claiming a known root cause or measured saving? Is there an actual brief rather than a promise to make one? Are missing permissions and production evidence still visible? Does the proposed pilot stay inside the requested draft-only scope?

Preserve the output before correcting it. Record the correction separately and inspect the revised artifact. A single run illustrates behavior on that task; it does not establish general product superiority. If access is blocked, record **Unavailable**, not a fabricated failure score.
